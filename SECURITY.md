# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 15.x    | :white_check_mark: |
| 14.x    | :white_check_mark: |
| < 14.0  | :x:                |

## Reporting a Vulnerability

Please report security issues privately. Do not open a public GitHub issue.

1. Prefer [GitHub private vulnerability reporting](https://github.com/unacms/una-g/security/advisories/new) on this repository (creates a draft GHSA the maintainers can publish after a fix).
2. Or email [team@unacms.com](mailto:team@unacms.com).

We will acknowledge the report and follow up on a fix. Reporters who want credit can be named on the advisory when it is published.
