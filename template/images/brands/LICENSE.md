# Brand marks

The marks in this folder come from [Simple Icons](https://simpleicons.org), released under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md): `linkedin.svg`
from simple-icons 13.21.0, the others from 16.38.0. Each file keeps the mark's path as published,
in a 28px box around Simple Icons' 24px one so a mark sits at the size of a Lucide icon.

The marks are trademarks of their owners. UNA shows them only to name the service a share or
sign-in button goes to.
