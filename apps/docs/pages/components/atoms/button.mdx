# Button

Buttons let users perform actions and make choices with a click or tap.

The Neo UI Button behaves similar to the native HTML `<button>`, so it wraps around the text 
that will be displayed on its surface.

## Variants

```jsx
import { Button } from 'app/design/controls';

<Button title="Default"  variant="default" />
<Button title="Primary"  variant="primary"  />
<Button title="Danger" variant="danger"/>
<Button title="Outline" variant="outline"/>
<Button title="text" variant="text"/>
<Button title="Link" variant="link"/>
```

## Sizes

<Button title="Base" startDecorator="home" size="base" />
<Button title="Large" startDecorator="home" size="lg" />
<Button title="XLarge" startDecorator="home" size="xl" />
<Button title="Full Width" fullWidth />
<Button title="Full Width Left" fullWidth align="start" startDecorator="home" />
<Button title="Full Width Right "  fullWidth align="end" endDecorator="home" />
