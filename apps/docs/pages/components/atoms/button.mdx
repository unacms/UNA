# Button

Buttons let users perform actions and make choices with a click or tap.  
The Neo UI Button behaves similar to the native HTML `<button>`, so it wraps around the text that will be displayed on its surface.

## Text button

```jsx
import {Button} from "app/design/controls";
<Button text onPress={() => alert('Hello World!')}>PRESS ME</Button>
```

<Wrapper>
    <Button text onPress={() => alert('Hello World!')}>PRESS ME</Button>
</Wrapper>

## Text primary button

```jsx
import {Button} from "app/design/controls";
<Button text variant="primary" onPress={() => alert('Hello World!')}>PRESS ME</Button>
```

<Wrapper>
    <Button text variant="primary" onPress={() => alert('Hello World!')}>PRESS ME</Button>
</Wrapper>
