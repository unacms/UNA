# Button

Buttons let users perform actions and make choices with a click or tap.

The Neo UI Button behaves similar to the native HTML `<button>`, so it wraps around the text 
that will be displayed on its surface.

## Text Button

```jsx
import { Button } from 'app/design/controls';

<Button title="default"  type="default" />
```
