# Button

Buttons let users perform actions and make choices with a click or tap.

The Neo UI Button behaves similar to the native HTML `<button>`, so it wraps around the text 
that will be displayed on its surface.

## Text Button

```jsx
import { Button } from 'app/design/controls';

<Button text onPress={() => alert('Hello World!')}>
  Default Button
</Button>
```

<Wrapper>
  <Button text className='mx-auto' onPress={() => alert('Hello World!')}>
    Default Button
  </Button>
</Wrapper>

## Text Primary Button

```jsx
import { Button } from 'app/design/controls';

<Button text variant="primary"  onPress={() => alert('Hello World!')}>
  Primary Button
</Button>
```

<Wrapper>
  <Button text variant="primary" className='mx-auto' onPress={() => alert('Hello World!')}>
    Primary Button
  </Button>
</Wrapper>
