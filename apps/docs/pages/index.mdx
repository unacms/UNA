# NEO - The NEtworking Organiser

**NEO** - a universal app that sits on top of [UNA](https://una.io) and enables you to build both native and web apps for 
your social media networks and communities. 
NEO provides a limited yet purposeful set of user-facing UNA features, making it easier for you to streamline the user experience.

## Why Choose NEO?

The vast majority of social media users prefer to access their favorite platforms via mobile apps. 
However, developing and maintaining iOS and Android apps can be prohibitively expensive. Although web-apps, 
hybrid apps, and progressive web apps (PWAs) provide a more accessible alternative, they come with their
 own unique set of challenges. This is where NEO comes in - as a **universal** app, it uses a single codebase that can 
 compile into a search engine optimized React Web-App, as well as fully-native iOS and Android apps.

## Powered by:

NEO leverages the power of the technologies such as Expo, Next.js, React Native Web, TailwindCSS, Turborepo, 
and Solito, ensuring that you have access to the best tools to build and maintain your apps.
